# 🖥️ Sistema de Chamados TI - MVP

## Sobre
Protótipo de interface para abertura e resolução de chamados de suporte de TI.

## Tecnologias
- HTML5
- CSS3
- JavaScript (Vanilla)

## Estrutura do projeto

```
Trabalho-Curso/
├── login.html
├── abrir_chamado.html
├── resolver_chamados.html
├── css/
│   ├── style.css
│   ├── abrir-chamado.css
│   └── resolver-chamados.css
├── js/
│   ├── app.js
│   ├── abrir-chamado.js
│   └── resolver-chamados.js
├── assets/
└── docs/
    ├── checklist-boas-praticas.md
    └── melhorias.md
```

## Como rodar
1. Baixe o projeto
2. Abre `login.html` no navegador
3. Use as credenciais: `admin/admin` ou `user/user`
